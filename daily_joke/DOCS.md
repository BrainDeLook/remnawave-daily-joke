# Настройка

1. Укажите HTTPS-адрес своей панели в `panel_url` (можно секретную ссылку `/auth/login?...`).
2. Впишите API-ключ Remnawave в `api_key`.
3. Если вместо ссылки используете cookie вручную — заполните `cookie` строкой `имя=значение`.
4. Замените `examples` своими анекдотами, задайте время `daily_time` и часовой пояс `timezone`.
5. Сначала запустите с `dry_run: true`. В журнале появится анекдот; панель изменяться не будет. Генерация выполняется после заданного времени (для немедленной проверки поставьте `00:00`).
6. Для публикации выключите `dry_run`, сохраните и перезапустите дополнение.

Первая загрузка модели требует интернета и свободного места. После генерации модель выгружается из RAM. Все изменения конфигурации требуют перезапуска. По умолчанию используется Qwen2.5 1.5B. Если мало памяти, выберите 0.5B; при наличии запаса можно 3B.

Меняется глобальный заголовок `announce` в Subscription Settings; остальные заголовки сохраняются. External Squads могут переопределять его. Клиент VPN увидит новый текст после обновления подписки, если поддерживает announce.

API-ключу нужны чтение и изменение Subscription Settings. Текст анекдота генерируется локально, внешних LLM API нет. Не отключайте TLS и не публикуйте ключи/секретные ссылки. Для панелей с CAPTCHA/JS/MFA потребуется отдельный разрешённый способ API-доступа.

Полная инструкция и ограничения: https://github.com/BrainDeLook/remnawave-daily-joke
