# Настройка

## Tooken Club API (с версии 0.1.4)

Для облачной генерации задайте `provider: tooken`, отдельный ключ `tooken_api_key` и модель `tooken_model: gpt-6.1-terra` (с версии 0.1.5). Для сравнения можно выбрать `gpt-6.1-sol`. Поле `api_key` оставьте с ключом Remnawave. После сохранения перезапустите дополнение и нажмите **Сгенерировать предпросмотр**. GPT используют Responses; остальные модели — Chat Completions. Другой ID можно взять из Tooken `/v1/models`.

В этом режиме Ollama не запускается. За запуск отправляется один платный запрос; предпросмотр тоже платный. Выбранное количество примеров и до трёх недавних анекдотов передаются Tooken Club. Адрес панели, ключ Remnawave и cookie в запрос не включаются. Точный расход из `usage` виден на странице и в журнале; цену и коэффициент списания смотрите в кабинете Tooken. При ошибке автоматических платных повторов в этот день нет; доступен повтор вручную. Качество и доступность модели на вашем аккаунте проверяются предпросмотром.

Примерный расход с короткими примерами — 1000–3000 токенов за запуск; reasoning может увеличить расход. При базовых 6 ₽/млн до коэффициента и одинаковых 2000 токенов Terra (0,8×) — около 0,0096 ₽, Sol (1,1×) — около 0,0132 ₽. Не умножайте на коэффициент уже пересчитанную цену. Фактическая сумма определяется кабинетом. Лимит Chat — 512 выходных токенов; Responses — 1024 вместе с reasoning. У Terra reasoning отключён, у остальных GPT — low. Для возврата к локальной генерации выставьте `provider: local` и перезапустите.

## Общие настройки

1. Укажите HTTPS-адрес своей панели в `panel_url` (можно секретную ссылку `/auth/login?...`).
2. Впишите API-ключ Remnawave в `api_key`.
3. Если вместо ссылки используете cookie вручную — заполните `cookie` строкой `имя=значение`.
4. Замените `examples` своими анекдотами. В `example_count` укажите число случайных примеров или 0 для всех (по умолчанию 8); затем задайте время `daily_time` и часовой пояс `timezone`.
5. Сначала запустите с `dry_run: true`. Откройте **Веб-интерфейс → Сгенерировать предпросмотр**. Анекдот появится на странице и в журнале; панель изменяться не будет. Кнопку можно нажимать повторно после завершения генерации, независимо от расписания.
6. Для публикации выключите `dry_run`, сохраните и перезапустите дополнение.

В режиме публикации кнопка называется **Сгенерировать и опубликовать** и меняет анонс сразу. После успешного ручного запуска автоматический запуск в этот день пропускается; сама кнопка остаётся доступной. При незавершённой публикации повторный запуск использует сохранённый анекдот, чтобы безопасно повторить запись. Изменение времени и обычный перезапуск не сбрасывают отметку выполненного дня.

Веб-интерфейс доступен через Home Assistant Ingress, отдельный порт на хосте открывать не нужно. В Docker Compose эта кнопка недоступна; автоматическое расписание работает как раньше.

После обновления до 0.1.3 вручную выберите `model: qwen3:4b-instruct`, сохраните конфигурацию и перезапустите дополнение: выбранная ранее модель автоматически не заменяется. Qwen3 — новая модель по умолчанию только для новых установок. Первое скачивание — около 2,5 ГБ. RAM нужна дополнительно под контекст и служебные данные; пригодность для нагруженного HA проверяйте на своём устройстве.

В режиме local один запуск делает три последовательные попытки генерации, затем та же модель отдельным запросом выбирает связный вариант с понятной концовкой. Если все варианты отклонены или ответ проверки некорректен, анонс не меняется. Это эвристическая проверка, а не гарантия качества юмора. Веса модели не обучаются: выбранные примеры задают стиль запроса. Большой список увеличивает контекст и нагрузку на локальную модель.

В RAM разрешена только одна модель (`OLLAMA_MAX_LOADED_MODELS=1`), запросы выполняются последовательно. После каждого запроса `keep_alive: 0` выгружает модель; между запусками остаётся сервер Ollama. Смена модели применяется после перезапуска, который завершает старый процесс. Скачанные файлы прежних моделей остаются на диске и не означают, что модели загружены в RAM. Если памяти недостаточно, верните Qwen2.5 1.5B/3B. Все изменения конфигурации требуют перезапуска.

Если текущий `announce` начинается с текста в квадратных скобках, например `rwEncodeBase64: [Финляндия снова работает]`, этот блок сохраняется; новый анекдот добавляется после пустой строки. Чтобы изменить или удалить блок, отредактируйте его в панели Remnawave. Скобки внутри старого анекдота не сохраняются.

Меняется глобальный заголовок `announce` в Subscription Settings; остальные заголовки сохраняются. External Squads могут переопределять его. Клиент VPN увидит новый текст после обновления подписки, если поддерживает announce.

Ключу Remnawave нужны чтение и изменение Subscription Settings. В режиме local текст генерируется локально; в режиме tooken — через внешний API. Не отключайте TLS и не публикуйте ключи/секретные ссылки. Для панелей с CAPTCHA/JS/MFA потребуется отдельный разрешённый способ API-доступа.

Полная инструкция и ограничения: https://github.com/BrainDeLook/remnawave-daily-joke
