## 0.1.9

- Tooken генерирует три варианта в одном запросе и выбирает лучший; некорректный ответ не публикуется.
- Три последних предпросмотра сохраняются отдельно и учитываются в следующих предпросмотрах.

## 0.1.8

- Промпт задаёт чёрный юмор и просит менять темы, ситуации и персонажей относительно недавних анекдотов.

## 0.1.7

- Обновлён промпт: модель ориентируется на приёмы и формат примеров.
- Текст в квадратных скобках в начале текущего анонса сохраняется перед новым анекдотом.

## 0.1.6

- Добавлена настройка количества примеров для обоих режимов: 0 означает все; по умолчанию 8.

## 0.1.5

- Добавлен Responses API для GPT-моделей, включая Terra и Sol, с разбором текстовых блоков и usage.
- Terra — начальная облачная модель с reasoning=none; Sol и другие GPT используют low. Лимит Responses — 1024 токена вместе с рассуждениями.
- Gemini, Claude, DeepSeek и остальные модели сохраняют маршрут Chat Completions. Выбор модели доступен через tooken_model.

## 0.1.4

- Добавлен Tooken Club через Chat Completions: отдельный ключ и настраиваемый ID модели, начальный вариант Gemini 3.8 Flash.
- В API-режиме Ollama не запускается; за генерацию отправляется один запрос с лимитом ответа 512 токенов.
- В журнале и веб-интерфейсе отображается фактический usage; автоматические платные повторы после ошибки отключены до следующего дня, ручной повтор доступен.
- Локальный режим, ручной запуск и rwEncodeBase64 сохранены. Примеры и недавние анекдоты в API-режиме отправляются Tooken Club.

## 0.1.3

- Добавлена Qwen3 4B Instruct; модель по умолчанию для новых установок. При обновлении выберите её вручную и перезапустите дополнение.
- Три последовательных кандидата и отдельный выбор связного анекдота с концовкой вместо публикации первого формально допустимого текста.
- Некорректная проверка, отклонение всех вариантов и обрыв текста не приводят к публикации.
- Сохранены keep_alive=0 после каждого запроса и ограничение одной модели в RAM. CI проверяет реальную генерацию Qwen3 и выгрузку через /api/ps для ARM64/AMD64.

## 0.1.2

- Добавлен веб-интерфейс Home Assistant Ingress с ручным запуском независимо от времени и сегодняшнего выполнения.
- Предпросмотр показывает анекдот на странице и в журнале; режим публикации записывает его в Remnawave.
- Генерация выполняется последовательно: повторные нажатия во время работы не создают очередь запросов.
- Исправлена инструкция предпросмотра: смена времени не сбрасывает отметку выполненного дня.

## 0.1.1

- Announce сохраняется как `rwEncodeBase64:` + исходный русский текст; кодирование выполняет Remnawave.
- Готовые версионные образы ARM64 и AMD64 публикуются в GHCR после тестов; сборка на RPi не нужна.
- Добавлены проверки запуска Ollama и импорта Python внутри каждого образа.

## 0.1.0

- Первоначальная версия с локальной генерацией и предпросмотром.
